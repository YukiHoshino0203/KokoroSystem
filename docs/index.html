Attaches an emotional layer to LLMs. Computes KRV via formulas and modulates responses transparently.

2) Why it’s built

A. I’m anxious about tomorrow’s talk.
B. Tomorrow’s talk went fine, but I still feel uneasy.

Overview

KokoroSystem formalizes emotion as structured objects (Integrity, Layer, Time, Vector) and computes a Kokoro Resonance Vector (ER/GR/SR/IHR). The 3-stage pipeline is: Llama2 emotion extraction → mathematical KRV → response generation. Safety is governed by PMC (coherence checks).
